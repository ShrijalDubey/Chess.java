# Chess.java

A **Java-based Chess game** that allows two players to play chess through a console interface. The project focuses on implementing chess rules and game logic using **Object-Oriented Programming** concepts.

## Features

* Two-player local gameplay
* Standard 8×8 chess board
* Legal move validation
* Turn-based gameplay
* Piece movement and captures
* Check and checkmate detection
* Pawn promotion
* Console-based board display

## Tech Stack

* **Java**
* Object-Oriented Programming (OOP)
* Classes & Objects
* Arrays
* Methods & Control Flow

## Run Locally

```bash
git clone https://github.com/ShrijalDubey/Chess.java.git
cd Chess.java
javac *.java
java Main
```
